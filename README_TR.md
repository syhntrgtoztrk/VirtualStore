# VirtualStore Android test app

Bu proje, mevcut VirtualStore prototipini Android WebView uygulamasına sarar.

## Android Studio ile çalıştırma
1. Android Studio'yu açın.
2. `VirtualStore_Android_Test` klasörünü Open ile açın.
3. Gradle sync tamamlandıktan sonra bir Android emulator veya USB hata ayıklama açık telefon seçin.
4. Run ▶️ ile kurun.

Uygulama şu anda DEMO ürün verileri kullanır. Canlı mağaza taraması henüz bağlanmış değildir.

## Canlı sürüm
Sonraki aşamada mağaza API/affiliate/feed bağlantıları backend üzerinden eklenmelidir; API anahtarları Android uygulamasına gömülmemelidir.
